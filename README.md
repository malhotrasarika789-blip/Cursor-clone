Cursor.com Website Clone
This project is a basic frontend clone of the Cursor.com website, created for learning and practice purposes.
I built this project to improve my HTML, CSS, and basic layout skills.
This is a beginner-level project and focuses mainly on structure, layout, and responsiveness.

 Project Overview


Static website (no backend)


Clean UI inspired by Cursor.com


Responsive layout


Beginner-friendly code structure



 Technologies Used


HTML5 – for page structure


CSS3 – for styling and layout


VS Code – as code editor
